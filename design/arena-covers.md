# Capas de arenas

Ilustrações SVG originais por modalidade: society, beach tennis, vôlei, futevôlei e modalidade genérica. A modalidade filtrada tem prioridade; sem filtro usa ordem society, beach tennis, vôlei, futevôlei. Fotos cadastradas prevalecem, e falhas de carregamento mostram a ilustração. As capas informam que são ilustrativas. Sem scraping, API paga ou alteração de dados das arenas.
